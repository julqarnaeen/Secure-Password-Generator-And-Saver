## Secure Password Generator and Saver

This project is a PHP/MySQL web app for generating strong passwords and storing them securely. It supports saving, viewing, and deleting password entries from a simple web interface.

## run

1. Install XAMPP.
2. Open XAMPP and start Apache and MySQL.
3. Open the XAMPP folder and navigate like this:

	XAMPP->htdocs->Create File.

4. Copy this project folder into the file you created under `htdocs`.
5. Open phpMyAdmin and create a database, then use the SQL in `db_connect.php` (or update it for your DB).

## Files

- `index.php` - main UI
- `save_password.php` - save password entry
- `delete_password.php` - delete password entry
- `db_connect.php` - database connection setup
